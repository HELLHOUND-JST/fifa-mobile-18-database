FIFA MOBILE 18 — BASE INTEGRAL (SEASON 2) — V5.0.0
====================================================

RESUMEN
-------
V5.0.0 integra cartas base, cartas de eventos/programas, estadísticas,
Skill Boosts e inventarios de recursos gráficos: jugadores PNG, cartas
completas, logos, iconos, escudos y fondos.

ESTADISTICAS Y SKILL BOOSTS
---------------------------
Según el responsable del proyecto, las estadísticas oficiales del juego y
los Skill Boosts oficiales se obtienen de RenderZ.

El resumen técnico documenta para la base un desglose de 13.620 registros
del motor + 265 registros de guía = 13.885. La documentación conserva este
desglose y recomienda consultar fuentes/metadatos del registro.

  Cartas base:                    13.885
  PNG individuales de jugadores: 13.885
  Cartas base completas:         13.885

HERRAMIENTAS NUEVAS IDENTIFICADAS EN V5
---------------------------------------
  fetch_mobile_stats.py
  fix_mobile_stats.py
  generate_iconos_assets.py

Se conservan herramientas de extracción y generación de versiones previas.
Consulta --help antes de ejecutar scripts:
  python fetch_mobile_stats.py --help
  python fix_mobile_stats.py --help
  python generate_iconos_assets.py --help

ESTRUCTURAS JSON
----------------
  Base: incluye total_stats y goalkeeping siempre presente.
  Eventos: objeto superior has_meta con metadata y players.
  Ejemplo de lectura mencionado: carta CR con ID 1736.

GIT LFS
-------
El repositorio contiene recursos gráficos grandes gestionados con Git LFS.
Instala y configura Git LFS para recuperar los objetos reales al clonar.
Los recuentos de transferencia dependen de cada commit y subida.
