FIFA MOBILE 18 - TEMPORADA 2 - BASE DE CARTAS, ESTADISTICAS E IMAGENES
======================================================================

PROYECTO
--------
Proyecto comunitario e independiente para recopilar, organizar y consultar
informacion de las cartas base de FIFA Mobile 18 Season 2.

VERSIONES
---------
  1.0.0  Base inicial de cartas y exportaciones.
  2.0.0  Incorporacion de atributos principales, estadisticas detalladas
y        campos especificos para porteros.
  3.0.0  Incorporacion de PNG individuales de jugadores y PNG de cartas
         base completas, con manifiestos y herramientas de generacion.

ARCHIVOS PRINCIPALES
--------------------
  fifa_mobile_18_base.csv
    Base principal de cartas. Una fila por carta base. Delimitador: punto y coma.

  fifa_mobile_18_base.json
    Base principal en JSON, con campos adicionales UTF-8.

  fifa_mobile_18_base.txt
    Vista de texto plano de la base principal.

  fifa_mobile_18_base_player_stats.csv
    Base de cartas ampliada con atributos principales y detallados.

  fifa_mobile_18_base_player_stats.json
    Exportacion JSON estructurada por jugador, carta y estadisticas.

  fifa_mobile_18_base_player_stats_SAMPLE.json
    Muestra reducida del JSON estadistico.

IMAGENES DE JUGADORES
---------------------
  players_png/
    13.885 PNG individuales de jugadores, organizados por rareza.
    Dimensiones documentadas: 256 x 256 pixeles.
    No incluyen el fondo, el escudo ni el marco completo de la carta.

  players_png_manifest.csv / players_png_manifest.json
    Inventario de los PNG individuales.

  download_player_png.py
    Herramienta para descargar imagenes individuales.

CARTAS COMPLETAS
----------------
  cards_full/
    13.885 composiciones PNG de cartas base completas, organizadas por rareza.
    Dimensiones documentadas: 256 x 256 pixeles.

  cards_full_manifest.csv / cards_full_manifest.json
    Inventario de las cartas completas generadas.

  generate_full_cards.py
    Herramienta para generar las composiciones PNG de cartas completas.

BASE Y ARCHIVOS AUXILIARES
--------------------------
  missing_in_renderz.csv
    IDs para los que no se obtuvo una ficha base durante la extraccion.

  programs_excluded.csv
    IDs de cartas de programas/eventos excluidas de la base principal.

  data/cache_sofifa_list.json
    Lista de referencia SoFIFA.

  data/cache_renderz.jsonl
    Cache de consultas de fichas RenderZ.

  data/cache_guide_stats.jsonl
    Cache de referencia de atributos.

  data/cache_png_downloads.jsonl
    Cache reanudable para descargas de PNG individuales.

  data/manual_overrides.json
    Correcciones manuales del extractor principal.

  data/progress.json
    Contadores y fecha de la ultima ejecucion del extractor.

COMO USAR LAS HERRAMIENTAS
--------------------------
Requisito recomendado: Python 3.10 o superior.
Ejecuta desde la carpeta raiz del repositorio.

  Extractor principal:
    python extract_fifa18.py --test
    python extract_fifa18.py --help

  Descargar PNG individuales:
    python download_player_png.py --test
    python download_player_png.py --workers 12
    python download_player_png.py --only-ids 20801,158023
    python download_player_png.py --help

  Generar cartas completas:
    python generate_full_cards.py --test
    python generate_full_cards.py --workers 8
    python generate_full_cards.py --workers 8 --overwrite
    python generate_full_cards.py --help

ESTADISTICAS
------------
  stats.primary      Seis atributos principales segun la posicion.
  stats.detailed     Atributos detallados para jugadores de campo o porteros.
  stats.goalkeeping  Diving, positioning, reflexes y handling para porteros.

En el JSON, null identifica un bloque que no aplica. En el CSV, algunas celdas
pueden quedar vacias cuando el atributo no corresponde a la posicion.
