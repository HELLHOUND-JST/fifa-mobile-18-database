FIFA MOBILE 18 - TEMPORADA 2 - BASE DE CARTAS Y ESTADISTICAS
============================================================

PROYECTO
--------
Proyecto comunitario e independiente para recopilar, organizar y consultar
informacion de las cartas base de FIFA Mobile 18 Season 2.

La version 2.0 incorpora una exportacion adicional con atributos principales,
estadisticas detalladas y campos especificos para porteros.

ARCHIVOS PRINCIPALES
--------------------
  fifa_mobile_18_base.csv
    Base principal de cartas. Una fila por carta base. Delimitador: punto y coma.

  fifa_mobile_18_base.json
    Base principal en JSON, con campos adicionales UTF-8.

  fifa_mobile_18_base.txt
    Vista de texto plano de la base principal.

  fifa_mobile_18_base_player_stats.csv
    Base de cartas ampliada con atributos principales y detallados.

  fifa_mobile_18_base_player_stats.json
    Exportacion JSON estructurada por jugador, carta y estadisticas.

  fifa_mobile_18_base_player_stats_SAMPLE.json
    Muestra reducida del JSON estadistico.

  missing_in_renderz.csv
    IDs para los que no se obtuvo una ficha base durante la extraccion.

  programs_excluded.csv
    IDs de cartas de programas/eventos excluidas de la base principal.

FUENTES DE REFERENCIA
---------------------
  RenderZ: informacion de cartas base.
  SoFIFA: referencia historica de jugadores FIFA 18.
  FIFAMobileGuide: referencia reconocida durante la recopilacion y organizacion
  de atributos de jugadores.

Los nombres y materiales de terceros pertenecen a sus respectivos titulares.
La atribucion no implica afiliacion ni concede permisos de redistribucion.

COMO USAR EL EXTRACTOR PRINCIPAL
--------------------------------
Requisito recomendado: Python 3.10 o superior.
Ejecuta desde la carpeta raiz del repositorio.

  Prueba rapida:
    python extract_fifa18.py --test

  Procesar hasta 200 IDs:
    python extract_fifa18.py --limit 200

  Extraccion completa o reanudacion:
    python extract_fifa18.py

  Regenerar CSV/TXT/JSON principal desde las caches:
    python extract_fifa18.py --export-only

  Consultar IDs concretos:
    python extract_fifa18.py --only-ids 20801,158023,190871

  Cambiar el numero de trabajadores:
    python extract_fifa18.py --workers 4

  Corregir nombre o media:
    python extract_fifa18.py --set-name 20801 "Cristiano Ronaldo"
    python extract_fifa18.py --set-ovr 20801 91
    python extract_fifa18.py --export-only

  Consultar todas las opciones:
    python extract_fifa18.py --help

ESTRUCTURA DE ESTADISTICAS
--------------------------
  stats.primary      Seis atributos principales segun la posicion.
  stats.detailed     Atributos detallados para jugadores de campo o porteros.
  stats.goalkeeping  Diving, positioning, reflexes y handling para porteros.

En el JSON, null identifica un bloque que no aplica. En el CSV, algunas celdas
pueden quedar vacias cuando el atributo no corresponde a la posicion.

NOTAS IMPORTANTES
-----------------
  - La base principal contiene cartas base; las cartas de programas/eventos
    detectadas se conservan en un archivo separado.
  - La media Mobile y la media de FIFA 18 para consola pertenecen a contextos
    distintos y pueden no coincidir.
  - Los datos se ofrecen como referencia comunitaria, sin garantia de exactitud,
    integridad o disponibilidad. No se certifica cada valor como dato oficial.
  - Respetar las condiciones de las plataformas consultadas y no redistribuir
    materiales de terceros sin los permisos necesarios.
  - La atribucion a FIFAMobileGuide, RenderZ o SoFIFA no sustituye autorizacion.
